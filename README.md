# 🇬🇧 CryptoRankUK – Crypto Exchange Comparison Site

An independent UK crypto exchange comparison and affiliate site. SEO-optimised, ad-ready, and built to rank for high-value UK crypto keywords.

## 🚀 Go Live

Go to `Settings → Pages → Source: main / root`

Live at: `https://reluctant-coder-oss.github.io/crypto-exchange-compare/`

## 💰 Monetisation

1. **Replace `YOURREF`** in all affiliate links with your actual referral codes:
   - Kraken: `https://www.kraken.com/affiliate`
   - Coinbase: `https://www.coinbase.com/affiliates`
   - Binance: `https://www.binance.com/en/activity/affiliate`
   - Revolut: `https://www.revolut.com/referral-programme`
2. **Add ad network code** – replace `ad-placeholder` divs with Coinzilla/Bitmedia tags
3. **Add more exchange reviews** – each review page targets a high-value keyword

## 🔍 SEO Features

- FAQ schema (FAQPage JSON-LD) for Google rich results
- Review schema (Review JSON-LD) on each exchange review page
- Canonical URLs, Open Graph, meta descriptions on every page
- Beginner's guide targets "how to buy crypto UK" – high volume keyword
- `sitemap.xml` + `robots.txt` included
